# Lessons learned

- Distinguish installed libraries from working, validated integrations.
- Allocate measurable acceptance criteria to every system capability.
- Character consistency cannot be guaranteed by prompt length alone.
- Test unforeseen paraphrases, hallucinations and situational judgment.
- Handle turn-taking with deterministic cancellation and audio state logic.
- Benchmark multi-stage latency, not only local text generation speed.
- Separate synthetic QA, real microphone trials and subjective validation.
- Preserve rollback paths and avoid claiming complete physical behavior
  from simulations or isolated unit tests.
