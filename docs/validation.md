# Validation

Validation layers:
1. Unit tests for state machines, adapters and input processing.
2. Integrated service tests with logs, latency measurements and health probes.
3. Dialogue scenario suites including paraphrases and negative examples.
4. Real audio and sensor tests with controlled environmental assumptions.
5. Human review for subjective voice and consistent character behavior.

A passing text prompt is not a passing microphone interaction.
A software playback command does not prove audible start latency.
Synthetic loopback does not prove reliable, hands-free barge-in.
Prototype tests are not production acceptance.
